# خودرو من | MyGarage

نسخه 2.1.0 — اپلیکیشن آفلاین مدیریت و نگه‌داری خودرو

## قابلیت‌ها
- رابط فارسی و راست‌چین (RTL)
- طراحی Gold Glass مات با حالت تاریک و روشن
- ذخیره‌سازی محلی با SQLite؛ بدون حساب کاربری و بدون سرور
- ثبت، ویرایش، دسته‌بندی، تکمیل و حذف سرویس‌ها
- پیگیری سررسید بر اساس کیلومتر و تاریخ
- اعلان یادآوری روزانه برای سرویس‌های نزدیک به موعد
- ویرایش سریع کیلومتر و مشخصات خودرو
- تهیه و بازیابی فایل پشتیبان JSON
- سازگار با Android 7.0 به بالا

## ساخت APK
از GitHub Actions و Workflow با نام **Build MyGarage APK** استفاده کنید.
فایل خروجی در Artifact با نام `MyGarage-debug` قرار می‌گیرد.
پس از دانلود ZIP مربوط به Artifact، آن را استخراج و فایل `app-debug.apk` را نصب کنید.

## حریم خصوصی
تمام اطلاعات در حافظه داخلی دستگاه ذخیره می‌شود. برنامه برای عملکرد اصلی به اینترنت نیاز ندارد.
