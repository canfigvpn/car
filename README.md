# خودرو من | MyGarage 2.0

بازسازی مستقل اپ مدیریت و نگهداری خودرو با رابط فارسی و تم Gold Glass.

## امکانات پیاده‌سازی‌شده
- رابط فارسی با چیدمان راست‌به‌چپ
- طراحی تیره/روشن با کارت‌های مات و جزئیات طلایی
- ذخیره‌سازی آفلاین با SQLite روی دستگاه
- ثبت خودرو و ویرایش سریع کیلومتر
- ثبت سرویس، موعد کیلومتری/تاریخی، تکمیل یا حذف سرویس
- یادآوری روزانه سرویس‌ها با اعلان اندروید
- خروجی و بازیابی فایل JSON از طریق انتخاب‌گر فایل اندروید
- ساخت APK آزمایشی با GitHub Actions

## ساخت APK
از بخش **Actions** ورک‌فلو **Build MyGarage APK** را اجرا کنید. فایل `app-debug.apk` در Artifact با نام `MyGarage-debug` قرار می‌گیرد.

## ساختار
- `app/`: پروژه اندروید قابل ساخت
- `sources/` و `resources/`: خروجی استخراج‌شده نسخه قبلی، صرفاً برای مرجع و مقایسه؛ در Build جدید استفاده نمی‌شوند.

## نکته
نسخه فعلی یک پایه اجرایی مستقل است. اطلاعات فقط روی همان دستگاه ذخیره می‌شود. برای اعلان‌ها، مجوز اعلان در Android 13 به بعد باید تأیید شود.
