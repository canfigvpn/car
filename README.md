# خودرو من — MyGarage 3.7.0

دفترچه سرویس آفلاین و فارسی برای ثبت نگهداری یک خودرو.

## امکانات
- صفحه خانه با جست‌وجوی اختصاصی، تاریخچه، گزارش هزینه، پشتیبانی و درباره ما
- ثبت و ویرایش کیلومتر فعلی خودرو
- فهرست سرویس‌ها با جست‌وجو، فیلتر دسته و مرتب‌سازی
- وضعیت سرویس‌ها: ثبت‌نشده، به‌روز، نزدیک موعد و عقب‌افتاده؛ بدون برچسب رنگی «نیازمند بررسی»
- ورود تاریخ شمسی با تقویم انتخابی، دکمه تاریخ امروز و اعتبارسنجی تاریخ
- کیلومترشمار دیجیتالی با جداکننده خودکار هزارگان و دکمه درج کیلومتر فعلی در فرم عملیات
- راهنمای مستقل بررسی، تعویض و علائم هشدار برای هر ۴۳ سرویس
- آستانه هشدار متناسب با بازه هر سرویس (۱۰ درصد باقی‌مانده)
- ثبت یکپارچه مراجعه به مکانیک با عنوان «تعمیر و تعویض و بررسی» و یادداشت نتیجه کار
- تاریخچه جزئیات و امکان حذف رکورد اشتباه با ثبت رویداد حذف
- گزارش مجموع هزینه‌ها، هزینه سال و ماه جاری و تفکیک هزینه بر اساس سرویس
- حالت روشن و تیره قابل انتخاب
- جست‌وجوی سرویس‌ها فقط در صفحه خانه
- خروجی پشتیبان JSON و بازیابی آن
- ذخیره‌سازی محلی آفلاین برای اطلاعات خودرو
- پشتیبان‌گیری دستی با فایل JSON
- پشتیبان‌گیری آنلاین مستقیم در Google Drive با Drive API و مشاهده فایل در drive.google.com
- آیکون مدرن با گوشه‌های گرد و Adaptive Icon اندروید
- رعایت نوار وضعیت، ناوبری و بریدگی نمایشگر

## حریم خصوصی و نگهداری اطلاعات
اطلاعات در فضای محلی برنامه ذخیره می‌شود. حذف داده‌های برنامه یا حذف نصب می‌تواند اطلاعات را پاک کند؛ به‌صورت دوره‌ای فایل JSON پشتیبان بگیر و در جای امن نگه دار.

## ساخت APK
GitHub Actions کد JavaScript را بررسی و APK دیباگ را می‌سازد، امضا و اعتبارسنجی می‌کند و با نام MyGarage-v3.7.0-APK منتشر می‌کند. از بخش Actions، اجرای موفق را باز کن و فایل را از قسمت Artifacts دانلود کن.

## نکته سرویس‌ها
بازه‌های اولیه صرفاً راهنمای قابل ویرایش‌اند و برای همه شرایط رانندگی یکسان نیستند. دستورالعمل سازنده خودرو و وضعیت واقعی قطعه بر هر بازه عمومی اولویت دارند.

## راه‌اندازی پشتیبان آنلاین Google Drive
1. در Google Cloud Console یک پروژه بساز و Google Drive API را فعال کن.
2. صفحه OAuth consent را تنظیم کن و یک OAuth Client از نوع Android بساز.
3. نام بسته باید دقیقاً `ir.ef3.mygarage` باشد و SHA-1 باید متعلق به کلید امضای ثابت APK باشد.
4. کلید امضای ثابت را در GitHub Actions Secrets با نام‌های `MYGARAGE_KEYSTORE_BASE64`، `MYGARAGE_KEYSTORE_PASSWORD`، `MYGARAGE_KEY_ALIAS` و `MYGARAGE_KEY_PASSWORD` تنظیم کن.
5. پس از نصب APK امضاشده با همان کلید، در بخش پشتیبانی حساب گوگل را انتخاب و دسترسی Drive را تأیید کن. فایل `MyGarage-Backup.json` در فضای Drive حساب انتخابی ذخیره می‌شود.

**مهم:** اگر APK بدون کلید ثابت ساخته شود، گواهی امضای آن ممکن است بین اجراهای GitHub Actions تغییر کند و برای به‌روزرسانی بدون حذف نصب مناسب نیست. کلید امضای نسخه نصب‌شده باید حفظ شود.

- انیمیشن انتقال صفحات، کارت‌ها و گزارش هزینه به‌همراه لودینگ آغازین ۳٫۵ ثانیه‌ای اضافه شده است.
