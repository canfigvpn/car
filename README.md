# خودرو من — MyGarage 3.0.0

دفترچه سرویس آفلاین و فارسی برای ثبت نگهداری یک خودرو.

## امکانات
- فقط دو صفحه: صفحه اصلی و تاریخچه
- ثبت و ویرایش کیلومتر فعلی خودرو
- فهرست سرویس‌ها با جست‌وجو، فیلتر دسته و مرتب‌سازی
- وضعیت سرویس‌ها: ثبت‌نشده، به‌روز، نزدیک موعد و عقب‌افتاده
- محاسبه موعد کیلومتری و زمانی با تقویم شمسی و اعتبارسنجی تاریخ
- آستانه هشدار متناسب با بازه هر سرویس (۱۰ درصد باقی‌مانده)
- ثبت چند عملیات مستقل برای هر قطعه: تعویض، بررسی، سرویس، نظافت و تعمیر
- تاریخچه جزئیات و امکان حذف رکورد اشتباه با ثبت رویداد حذف
- گزارش مجموع هزینه‌ها، هزینه سال و ماه جاری و تفکیک هزینه بر اساس سرویس
- حالت روشن و تیره قابل انتخاب
- جست‌وجو در تاریخچه
- خروجی پشتیبان JSON و بازیابی آن
- ذخیره‌سازی محلی؛ بدون حساب کاربری، سرور یا مجوز اینترنت
- آیکون مدرن با گوشه‌های گرد و Adaptive Icon اندروید
- رعایت نوار وضعیت، ناوبری و بریدگی نمایشگر

## حریم خصوصی و نگهداری اطلاعات
اطلاعات در فضای محلی برنامه ذخیره می‌شود. حذف داده‌های برنامه یا حذف نصب می‌تواند اطلاعات را پاک کند؛ به‌صورت دوره‌ای فایل JSON پشتیبان بگیر و در جای امن نگه دار.

## ساخت APK
GitHub Actions کد JavaScript را بررسی و APK دیباگ را می‌سازد، امضا و اعتبارسنجی می‌کند و با نام MyGarage-v3.0.0-APK منتشر می‌کند. از بخش Actions، اجرای موفق را باز کن و فایل را از قسمت Artifacts دانلود کن.

## نکته سرویس‌ها
بازه‌های اولیه صرفاً راهنمای قابل ویرایش‌اند و برای همه شرایط رانندگی یکسان نیستند. دستورالعمل سازنده خودرو و وضعیت واقعی قطعه بر هر بازه عمومی اولویت دارند.
